Cozy Cafe – Mobile App UI Design

☕ Cozy Cafe – **Mobile App UI Design**
A modern and clean Cafe Ordering Mobile App UI designed in Figma.
This project showcases a complete coffee shop ordering experience including Home, Menu, Cart, and Profile screens.

**🏠 Home Screen**

Welcome section

Search bar

Today’s Special banner

Categories (Coffee, Tea, Desserts, Snacks)

Popular items

Bottom navigation bar

**📋 Menu Screen**

Category filters

Item list with images

Price display

Add to Cart button

**🛒 Cart Screen**

Selected items list

Quantity increase/decrease

Promo code section

Subtotal & discount calculation

Checkout button

**👤 Profile Screen**

User details

My Orders

Favorites

Payment Method

Settings

Help & Support

Social media links
